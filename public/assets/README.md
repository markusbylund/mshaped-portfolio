# Publicerade assets

## Struktur

- `brand/` - Mshapeds egen brandbild.
- `cases/<projekt>/cover-16x10.webp` - huvudbild för desktop och sociala ytor.
- `cases/<projekt>/detail-01.webp` - kompletterande projektvy.
- `cases/<projekt>/mobile-4x5.webp` - mobilanpassad projektbild.
- `social/` - Open Graph-material.

Originalfiler sparas utanför `public/` i `assets/source/`. Kör `npm run assets:optimize` efter
att ett original har uppdaterats.
