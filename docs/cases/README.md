# Case-dokumentation

Den här mappen innehåller redaktionellt underlag för Mshapeds projekt. Texterna beskriver bara
sådant som kan verifieras i den nuvarande produkten. Resultat, kundcitat och externa länkar läggs
inte till innan det finns verkligt underlag och tillstånd att publicera dem.

Bildmaterial:

- Råmaterial: `assets/source/cases/<projekt>/`
- Webboptimerade bilder: `public/assets/cases/<projekt>/`
- Optimeringskommando: `npm run assets:optimize`
