# The Five Crystals assets

Third-party assets used by the game are stored in subfolders with their original license files.

- `kaykit/`: KayKit Adventurers Character Pack 2.0 by Kay Lousberg, CC0 1.0. Used for the knight, sword, rogue enemies, barbarian boss, axe, and shared animations.
- `nature/`: Stylized Nature MegaKit Standard by Quaternius, CC0 1.0. Used for trees, rocks, and grass patches.

The game should only copy assets it actually uses so the deployed bundle remains small.
