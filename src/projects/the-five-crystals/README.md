# The Five Crystals

En spelbar fantasy/action-adventure-prototyp byggd som en liten 3D vertical slice.
Första versionen fokuserar på känsla och spelbarhet i ett tempel i stället för att försöka bygga hela spelet direkt.

## Kör lokalt

Från portfolio-projektet:

```bash
npm run dev
```

Öppna sedan:

```txt
http://127.0.0.1:5173/projects/the-five-crystals
```

Spelet kan även köras direkt som statisk 2D-demo via:

```txt
public/games/the-five-crystals/index.html
```

## Kontroller

- Rörelse: WASD eller piltangenter
- Attack: Mellanslag eller vänster musknapp
- Interagera: E

## Färdigt i 3D-MVP:n

- Startskärm och tydlig onboarding
- En spelbar 3D-nivå: Whisperwood / Root Temple
- Rörelse, kamera, attack och skadefeedback
- Runpussel med rätt ordning
- Fiender som jagar spelaren
- Miniboss: Root Guardian
- Skogskristallen som belöning
- Portal och vinstsekvens för första slicen
- Låsta världar som visar framtida progression

## Nästa iteration

- Bygg nästa värld först när Root Temple känns riktigt bra.

## Portfolio-case

- Visa spel-loop, systemdesign och progression som diagram.
- Lyft fram att spelet bygger på en barns fantasi och har itererats från 2D till 3D.
- Beskriv designbeslutet att börja med en vertical slice i stället för att överbygga.
