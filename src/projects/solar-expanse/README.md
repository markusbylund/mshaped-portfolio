# Solar Expanse

Interaktiv solsystemsupplevelse byggd som ett isolerat portfolio-case.

## Struktur

- `SolarExpanse.tsx` - projektets route-komponent
- `components/` - projektunika UI- och scenkomponenter
- `data/` - planetdata
- `styles/` - projektunika styles

Den här mappen ska kunna lyftas ut till en separat app/domän med minimal påverkan på resten av portfolion.
